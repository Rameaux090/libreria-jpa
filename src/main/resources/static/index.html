API REST de Libros

Servidor Spring Boot funcionando correctamente. Esta no es la API: es solo una página informativa en la raíz.

Endpoints disponibles

Base URL: http://localhost:8099/api/libros

MétodoRutaDescripción
GET/api/librosLista todos los libros.
GET/api/libros?titulo=quijoteFiltra por título (parcial).
GET/api/libros/{id}Devuelve un libro por id.
POST/api/librosCrea un libro (JSON en el cuerpo).
DELETE/api/libros/{id}Elimina un libro por id.

Abrir consola H2

Datos de conexión: JDBC URL jdbc:h2:mem:libreriadb, usuario sa, contraseña vacía.

Ejemplo de uso

curl http://localhost:8099/api/libros
curl -X POST http://localhost:8099/api/libros \
  -H "Content-Type: application/json" \
  -d '{"autor":"Antoine de Saint-Exupéry","titulo":"El Principito","fechaPublicacion":"1943-04-06"}'
